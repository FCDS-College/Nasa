# Citation and Provenance Design

## 1. Purpose

The citation system ensures that scientific claims generated by the AI can be traced back to their supporting evidence.

---

## 2. Provenance Chain

The complete provenance chain is:

```text
Answer Claim
    ↓
Citation
    ↓
Chunk
    ↓
Document
    ↓
Document Version
    ↓
Original Source
```

---

## 3. Citation Object

Conceptual structure:

```python
Citation = {
    "citation_id": str,
    "document_id": str,
    "document_version": str,
    "chunk_id": str,
    "source": str,
    "source_url": str | None,
    "page": int | None
}
```

---

## 4. Claim-to-Evidence Mapping

Important generated claims should be associated with one or more retrieved evidence items.

Conceptually:

```python
ClaimEvidence = {
    "claim_id": str,
    "claim_text": str,
    "citation_ids": list[str]
}
```

---

## 5. Citation Validation

Before returning the final answer, the system should verify:

1. The cited chunk exists.
2. The chunk belongs to the referenced document.
3. The document version exists.
4. The citation metadata is valid.
5. The cited evidence was actually retrieved.
6. The citation does not point to fabricated or unrelated content.

---

## 6. Source Versioning

If a document changes, its version should change.

A citation should preserve the version used to generate the answer.

This prevents an answer from being attributed to a different version of the source later.

---

## 7. Missing Evidence

If a generated claim has no supporting retrieved evidence, the system should either:

* remove the unsupported claim, or
* explicitly mark it as unsupported/uncertain according to the system policy.

The preferred behavior for scientific claims is not to present unsupported claims as established facts.

---

## 8. Citation Coverage

Citation coverage can be evaluated during retrieval and generation evaluation.

A useful metric is:

```text
Citation Coverage =
supported important claims
/
total important claims
```

The exact evaluation methodology may be refined during Day 2.

---

## 9. Scientific Traceability Requirement

A user should be able to move from an AI-generated claim to the underlying source evidence.

This is a core requirement for scientific reliability.
