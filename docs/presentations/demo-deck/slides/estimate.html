FLAME IN FREEFALL · LIVE DEMO

The Flame Outcome Explorer answers one concrete question: will a droplet flame put itself out? Set oxygen, pressure, diluents, droplet size and fuel. A multinomial logistic regression, trained on 261 real FLEX tests from the ISS, estimates whether the flame self-extinguishes, breaks up, or burns to completion, and shows the most similar real flight tests beside it. It scores 0.54 macro-F1 against a 0.27 baseline, validated by holding out whole test days, and 0.86 ROC-AUC for extinction. Most importantly, it has a strict applicability domain. Ask about the lunar lander and it declines, because that pressure is below anything FLEX flew.
